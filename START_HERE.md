## ⚡ Comece Agora (Copie e Cole)

### Passo 1: Abra Git Bash
Clique com botão direito na pasta do projeto → "Git Bash Here"

**OU** abra Command Prompt:
```
Windows + R → cmd → Enter
cd C:\Users\Maycon\Desktop\Garagem.com-system
```

**❌ NÃO use PowerShell**

---

### Passo 2: Instale Dependências
```bash
npm install
```
⏱️ Aguarde 2-3 minutos

**Você verá algo assim:**
```
added 500+ packages in 2m
```

---

### Passo 3: Configure Banco de Dados
```bash
npm run db:push
```

**Seguido de:**
```bash
npm run db:seed
```

**Você verá:**
```
✅ Seed concluído com sucesso!
```

---

### Passo 4: Inicie o Servidor
```bash
npm run dev
```

**Você verá:**
```
▲ Next.js 14.0.0
- Local:        http://localhost:3000
- Environments: .env.local
```

---

## 🐛 Se Algo Não Funcionar

### Erro: "PowerShell não consegue executar"
**Solução**: Use Git Bash ou Command Prompt (não PowerShell)

### Erro: "Porta 3000 ocupada"
```bash
npm run dev -- -p 3001
```

### Erro: "Prisma client not found"
```bash
npm run db:generate
```

### Erro: "Module not found"
```bash
rm -rf node_modules
npm install
```
